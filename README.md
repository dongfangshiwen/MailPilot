# MailPilot · Flutter 邮件助手

Android 8.0+ 的独立 AI 与邮件助手。配置模型即可聊天，邮箱可选；长对话自动整理为滚动摘要，保留原始记录和近期对话。包含手机切换邮箱选项时换行跳动的修复，支持实时流式回答、Markdown、可配置思考模式与档位。全部可见页面使用 Dart / Flutter。手机直接连接用户配置的 IMAP / SMTP 邮箱和 HTTPS 模型 API，无自建后端，无 OCR，无内置大模型权重。

邮箱、附件、加密存储等 Android 能力通过平台通道复用，APK 不再编译 Jetpack Compose 界面。当前交付仅支持 Android；Web 入口用于界面预览。

1. 安装 `artifacts/MailPilot-1.0.0-flutter-release.apk`。与旧版使用相同包名和签名，可覆盖升级；请勿先卸载，以免删除本地数据。
2. 首页“添加模型”或设置 → 添加模型：填写名称、HTTPS Base URL、模型名和 API Key。Base URL 包含服务商的版本路径，例如 `https://api.example.com/v1`，也接受完整 `/chat/completions` 地址。高级参数默认收起。
3. 模型页选择服务商，高级参数选择思考模式、档位或预算；默认跟随服务商。选择内置型号或手动填写后直接保存，无需先测试。设置中的视觉助手支持自动同厂商协作或固定配置，连接诊断是可选操作。返回主页后即可直接提问，无需绑定邮箱。
4. 对话较长时显示“正在整理上下文”及批次进度；完成后通过左上角菜单 → 对话摘要查看，不在输入框上方常驻提示。近期对话和原始记录继续保留。生成摘要使用当前模型，产生额外请求及 Token 用量；查看已保存摘要不会再次调用模型。摘要可能遗漏细节，可继续补充纠正。原理见 [CONTEXT_MEMORY.md](docs/CONTEXT_MEMORY.md)。
5. 要使用邮件功能时，点击加号 → 选择邮件，或设置 → 添加邮箱。预设包含 QQ、163、阿里企业及阿里个人邮箱。QQ、163 使用授权码；阿里企业需允许第三方客户端，启用安全密码后使用该密码。各邮箱须先开启 IMAP / SMTP；其他服务器选择自定义。连接测试只验证登录，不发测试邮件。详见 [阿里邮箱接入说明](docs/ALIBABA_MAIL.md)。
6. 启动与切换文件夹只显示本地缓存；在“我的邮件”下拉或点击右上同步图标，后台同步当前账号每个文件夹最新 50 封，后续只补新增与未完成正文。同步时可继续浏览、聊天和编辑；再次点击转动图标可取消。文件夹名称可单独刷新，未读筛选使用缓存；邮件按日期倒序，每次加载更多为 50 封。主页加号 → 选择邮件，勾选资料，详情可选附件；附件名最多显示两行，长按查看全名。PDF 默认前 10 页，可调整。返回助手后再输入问题，选择或阅读不会自动调用模型。
7. 回答实时显示 Markdown，输入框内可停止；中断会保留部分回答。模型返回可展示的思考内容时，会实时展开显示，开始回答后自动折叠，可点击重新展开，历史会话也能查看。不返回思考的模型不会生成虚假的思考内容。可复制回答，点击来源编号核对原文。清空或重选资料保留当前会话和历史分析，每次问题使用独立资料快照。
8. 可以直接在聊天中告诉 Agent 目标邮箱和邮件内容，由它填写收件人、主题和正文，并展示邮件确认卡片。确认卡片显示完整正文和附件，点击“确认发送”（或紧接卡片回复“确认发送”）后，手机才通过 SMTP 提交。修改目标邮箱或正文后必须使用新的确认卡片，重复点击不重复发信。也可点“编辑邮件”手动编辑，完成后点“在聊天中确认发送”返回对话。缺少用途和内容时先追问，不把追问当作邮件正文。旧 Markdown 草稿通过右上角“更多邮件操作”转换；手动编辑不会在发送时被静默改写。发送结果不确定时先核实，应用不会自动重发。

草稿列表和确认卡片的“草稿操作”菜单可删除草稿或让助手重新拟写。默认保留地址和附件，成功后更新版本并重新确认。用户指定语言优先，回复跟随原邮件，重拟保留草稿语言。

普通收发不需要配置模型。后台同步默认关闭，可在设置主动开启；此前明确保存的同步频率会保留，可选择“关闭”。后台受 Android 调度和省电策略约束，不会分析或发送。真实模型服务的费用由用户自行承担。本版变化与验证范围见 [RELEASE_1_8.md](docs/RELEASE_1_8.md)。

## 1.8 新入口

顶部标题切换模型；输入框左侧为“思考／搜索”胶囊，右侧为加号和语音／发送。搜索、语音配置合并为底部抽屉，选项返回保留填写内容。深度思考按本轮保存，长按开关恢复模型默认；智能搜索默认关闭，在设置中配置火山联网搜索或博查的独立 API Key 后开启。网页标题、链接和检索内容可从来源入口查看。搜索从当前问题和所选资料、会话参考中提取必要公开关键词；显式起草和确认发送不触发搜索。

加号提供添加图片、添加文件、选择邮件，无邮箱也能分析手机文件。资料保留在当前会话，清空选择不会重开对话。草稿缺收件人时点击“补充收件人”，或说“发给 name@example.com”，核对新卡片后发送。“写成邮件”按完整回答 ID 起草，聊天不再显示内部提示词。

点击语音开始，再次点击结束；结果插入输入框，由你检查后发送。系统识别优先，缺少服务时可配置千问 ASR。云端录音最长 60 秒，使用请求内音频数据直传，临时录音完成或取消后删除。识别出“确认发送”不会自行发信。配置地址、协议、验证限制见 [1.7 使用说明](docs/RELEASE_1_7.md)。

## 支持的附件

DOCX / XLSX / PPTX：本地提取文字、表格、备注和嵌入图片；Excel 使用公式缓存值。PDF：系统逐页转图片，由用户配置的视觉模型阅读。JPG / PNG / WebP：直接视觉分析。TXT：本地读取常见编码。旧 DOC / XLS / PPT 需先转换。

单附件 20 MB；每轮分析最多 10 个附件、合计 50 MB、20 张图片或 PDF 页面（含 Office 嵌入图片），文字总量 24 万字。PDF 默认前 10 页，单份最多选择 20 页；视觉主模型默认一次接收完整图文，不再固定每批四张。最终编码请求体受 32 MiB 应用上限及已核实的厂商限制约束，超限后由用户调整资料或选择分批。未知大小和 PDF 实际页数在读取后检查，超过资料限制不调用模型。Office 解压读取上限 100 MB，不保证完整排版，不执行宏、公式或外部链接。单封发送附件仍为合计 20 MB。图片阅读准确性取决于模型，来源页可用于人工核对。

## Windows 构建

锁定 Flutter 3.47.2 / Dart 3.13.2、JDK 17–25、Android Platform 36 / Build Tools 36.0.0、NDK 28.2.13676358 / CMake 3.22.1、Gradle 9.3.1、AGP 9.1.0、Kotlin 2.2.20、KSP 2.3.6。Flutter 加入 PATH；脚本优先使用 `MAILPILOT_JAVA_HOME`、`JAVA_HOME`，随后探测 Android Studio 的 JBR。JDK 26 不用于本构建组合。

```powershell
.\scripts\Build.ps1 -Mode Debug
.\scripts\Build.ps1 -Mode Test
.\scripts\Build.ps1 -Mode Release
.\scripts\Build.ps1 -Mode Verify
.\scripts\Build.ps1 -Mode Test -DeviceTests -Device emulator-5558
.\scripts\Build.ps1 -Mode Test -DeviceTests -Device emulator-5562 -ExpectedApi 36
.\scripts\Package-Source.ps1
```

脚本写入 `android/local.properties`、复用本机 Windows HTTP 代理、运行分析 / 单元测试 / Lint，并按所选模式构建 APK。Gradle Wrapper 校验发行包 SHA-256。Release 首次构建会创建本地签名；已有签名时沿用。输出在 `artifacts/`，附带 SHA-256 文件。

如最新版 Android CLI 的 SDK Manager 兼容包装器未能自动安装 NDK，可使用 `android sdk install ndk/28.2.13676358` 预先安装，或在 Android Studio SDK Manager 安装相同版本。

Android Studio 中模拟器黑屏时，先停止设备并执行 Cold Boot；仍异常时使用 Software 图形模式。具体步骤及本机修复记录见 [模拟器黑屏排查](docs/ANDROID_STUDIO_TROUBLESHOOTING.md)。冷启动保留数据，不要将 Wipe Data 当作普通重启。

`lib/main_preview.dart` 也包含 Widget Preview 的 `@Preview` 入口。如果 Android Studio 的组件预览持续停在启动页面，依赖缓存准备好后，可在项目根目录运行 `./scripts/Start-WidgetPreview.ps1`。脚本把当前界面源码复制到独立的临时目录，使用离线依赖缓存，在浏览器中打开标准组件预览，避免项目内模拟器缓存的写入反复触发预览重载。修改原项目代码后，重新运行脚本可更新该预览。关闭预览窗口后，在启动它的终端中按 `q` 结束服务。

## 签名与数据备份

请单独安全备份整个 `.signing/` 目录，包含发布密钥和密码配置。后续升级必须沿用相同签名；丢失后无法覆盖升级。该目录不进入 Git 或源码 ZIP，不要分享密码。源码打包采用白名单，排除签名、凭据、缓存和本机 SDK 路径。

邮箱授权码和模型 Key 用 Android Keystore AES-GCM 加密；数据库、附件、会话及摘要保存在应用私有目录，禁用系统云备份。卸载会删除本机数据。设置的“清理缓存与聊天记录”会删除全部聊天及摘要；删除邮箱会删除其本地邮件、关联会话及草稿，独立普通聊天保留。
