# MailPilot 1.0.0（22）

继续作为 1.0.0 稳定测试版交付，用户验收前不升到 1.0.1。`pubspec.yaml` 为唯一版本来源，沿用 `app.mailpilot` 和原发布签名，覆盖升级基线为 1.0.0（21）。Room 保持 v8。

## 改动与原因

原来的“摘要未满足长度要求”由应用对空摘要、`null` 或固定 4,000 字符的校验触发，不能证明模型上下文已满。本轮以统一请求预算和可恢复分批整理替换这些旧分支。

- 已知官方型号自动匹配上下文；旧 32,768 默认值跟随型号，其他自定义额度保留。代理地址、未知型号和未确认别名仍使用手动设置。
- 模型设置提供“跟随型号／自定义”，显示当前额度、思考模式对应的官方输入上限及核实日期。最大输出默认 4096，保留用户设置。
- 有效输入先预留输出和适用的思考空间，预计达到 **95%** 时整理，目标 **60%**。估算覆盖系统提示、工具、问题、历史、资料与工具结果；底层发请求前再次检查上限。
- 保留当前问题及最近两轮完整对话，长历史和资料按预算分片合并。已有资料占用决定分配，不再固定给历史三分之一空间。
- 摘要建议长度与实际预算分开；有效但过长的候选最多额外精简两次。有效批次写入轮次检查点，失败、取消或重启后可手动继续；全部成功后才条件更新正式记忆。原始聊天不删除。
- 空内容、格式错误、输出截断、网络故障和精简后超限分别提示。压缩进度只在处理期间显示，完成后仍从会话菜单查看。
- “写成邮件”继续复用完整目标回答及已处理资料，不重新读取已取消选择的附件，不重新调用视觉模型。整理不改变草稿状态，也不提供 SMTP 工具。
- 添加邮箱新增“如何配置邮箱”：QQ、163、阿里企业及个人邮箱分别显示简洁步骤、SSL 参数和官方链接。底部抽屉可滚动、关闭和返回，保留表单内容；只有点击官方链接时才打开浏览器。自定义域名不猜测服务商。

95% 是本版明确选择的阈值，不宣称等同于 Codex 内部自动压缩策略。估算不是厂商精确 Token 计量；模型摘要有损，不能保证保留每个细节。详细机制见 [上下文说明](CONTEXT_MEMORY.md)，邮箱步骤与来源见 [邮箱配置](MAIL_SETUP.md)。

## 审查与兼容

新增 `ContextBudgetPlanner`、`ContextReducer`，扩展能力目录、DataStore 模式和 `AgentRunCheckpoint`。移除固定摘要长度、三分之一分配、未使用的字符分组方法和旧压缩入口；旧 JSON、原生数据迁移链、资料快照和发送保护继续保留。

检查点身份包含实际模型连接／凭据版本、预算与思考设置、会话及历史／资料内容，避免配置变化后复用不匹配结果。日志仅含阶段、预算、长度、批次、型号和错误类型。Windows 构建脚本修正 Flutter 重写 `local.properties` 后盘符冒号未转义造成的 Lint 错误。
