# MailPilot 1.8.1（11）

## 邮箱选择与输入框

“我的邮件”中的邮箱地址现在打开底部选择面板。账号名和邮箱域名分行显示，当前账号带勾选标记；支持滚动、关闭、深色主题和大字体。点击当前账号只关闭面板，切换账号仍只读取本地缓存，不自动同步。

输入框右侧为“添加附件＋语音／发送”。没有文字时只显示语音按钮；输入文字后，发送按钮在同一个位置替换语音按钮，清空文字后切回语音。麦克风不再出现在文字区，也不会和发送按钮同时占位。发送圆形背景从 48 dp 缩至 36 dp，实际点击区域仍为 48×48 dp，切换不跳动。录音中按钮用于结束录音；识别结果先进入输入框，检查后发送；生成回答时该位置显示停止按钮。思考／搜索保留紧凑胶囊，特别窄的可用空间允许工具选项横向滚动。

## 阿里企业邮箱真实同步修复

2026-09-08 使用用户提供的阿里企业邮箱进行只读测试。地址为 `imap.qiye.aliyun.com:993`，启用 TLS 和证书校验。账号能认证、能列出文件夹，但服务器拒绝应用的 `SEARCH OR SENTSINCE … SINCE …`，返回 `BAD invalid command or parameters`；各个日期条件单独查询可以成功。

通用 `CompatibleImapSearch` 仅在服务器明确以 BAD 拒绝 AND/OR 组合查询时，将条件分别查询，以并集／交集保持语义，并在本次文件夹查询中记住兼容模式。网络、认证、权限错误及单个条件的错误仍正常上报。日期排序、UID 增量游标和只读访问保持原有规则，不将邮件标为已读。

使用项目实际 `MailRepositoryImpl` 和临时内存数据库验证结果：

| 检查 | 结果 |
|---|---|
| 文件夹数 | 5 |
| 首次全文件夹同步 | 12 封，约 7.6 秒，无失败、正文完整 |
| 再次全文件夹同步 | 约 1.2 秒，12 封命中缓存，正文下载 0 次 |
| 收件箱单独读取 | 10 封，约 1.9 秒，正文完整 |
| 收件箱重复读取 | 约 1.1 秒，正文下载 0 次，未读状态一致 |

耗时来自本次开发机网络环境，不能保证手机端的固定速度。未发送邮件、未下载附件文件、未输出邮件内容；凭据仅从测试进程环境传入，不写入源码、日志或发布包。证据见 `test-evidence/release181-aliyun-live-imap.xml`。

复用真实 IMAP 验证时，设置进程环境变量 `MAILPILOT_LIVE_IMAP_USER`、`MAILPILOT_LIVE_IMAP_PASSWORD`、`MAILPILOT_LIVE_IMAP_HOST`，执行 `:app:testDebugUnitTest --tests app.mailpilot.LiveImapTest --no-daemon --rerun-tasks`，避免 Gradle 复用旧测试结果。不提供凭据时跳过，Host 未指定时沿用原 QQ 默认值。不要将真实密码保存到构建脚本或 Gradle 属性文件。

官方配置依据：[阿里邮箱服务器地址与端口](https://help.aliyun.com/zh/document_detail/36576.html)。客户端安全密码要求取决于企业策略；本次提供的凭据已通过 IMAP 认证。
