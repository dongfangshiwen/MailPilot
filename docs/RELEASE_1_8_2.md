# MailPilot 1.8.2（12）

## 输入框样式

根据用户提供的 DeepSeek 截图改进底部工具栏：

- 思考与搜索采用细描边胶囊，普通字号下视觉高度 32 dp；选中后浅蓝填充、蓝色图标与文字，未选中时为中性描边。保留本轮开关状态和原有长按配置操作。
- 宽度足够时显示轨道图标＋“深度思考”、地球图标＋“智能搜索”。空间不足时两个标签一起缩短为“思考／搜索”，大字体下按需要隐藏装饰图标；切换选中状态不改变宽度。
- 添加、语音、发送统一为 36×36 dp 圆形轮廓，添加与语音为深色描边，发送为蓝色填充。三者的点击区域均为 48×48 dp，中心对齐。
- 无文字时只有语音波形按钮；输入文字后发送按钮原位替换语音；清空文字后恢复语音，生成回答时显示停止。识别文字依旧先填入输入框，不自动发送。
- 浅色输入框使用白底、细边框与轻阴影，深色保留暗色底；输入区仍最多显示四行。

## 模型设置操作

保存模型与“更多”按钮并排放在表单末尾，不再纵向排列四个文字操作。更多打开跟随主题的底部面板，集中显示默认文字模型、固定视觉助手、连接诊断和删除；当前默认用途有勾选标记，删除单独确认。面板可滚动、关闭，返回不清空表单；设置用途不会暗中保存当前编辑内容。连接诊断仅在主动点击后执行。

本轮仅修改 Flutter 界面与版本号，邮箱、模型、搜索、语音协议和数据库结构沿用 1.8.1，不需要重新配置账号。
