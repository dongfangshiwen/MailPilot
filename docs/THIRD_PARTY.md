# 第三方组件与来源

| 组件 | 用途 | 许可／来源 |
| --- | --- | --- |
| Flutter / Dart / Material | 页面、主题、交互及平台通道 | BSD-3-Clause，https://github.com/flutter/flutter / https://dart.dev |
| flutter_markdown_plus 1.0.12 / markdown 7.3.1 | Markdown 解析、排版与选择 | BSD-3-Clause，https://pub.dev/packages/flutter_markdown_plus / https://pub.dev/packages/markdown |
| Kotlin / kotlinx.coroutines | 语言与协程 | Apache-2.0，https://github.com/JetBrains/kotlin |
| AndroidX Room / DataStore / WorkManager / ExifInterface | 存储、后台与图像方向 | Apache-2.0，https://developer.android.com/jetpack/androidx |
| OkHttp / Okio | HTTPS 和流式 API | Apache-2.0，https://github.com/square/okhttp |
| Eclipse Angus Mail / Activation | IMAP、SMTP、MIME | 项目分发的 EPL-2.0／GPL-2.0 with Classpath Exception 等许可，https://eclipse-ee4j.github.io/angus-mail/ |
| Jakarta Mail / Activation APIs | 邮件与数据处理接口 | 项目分发许可证，https://jakarta.ee/specifications/mail/ |
| jsoup | 邮件 HTML 清理 | MIT，https://jsoup.org/ |
| CommonMark Java 0.30.0、GFM tables / strikethrough | AI Markdown 转换为邮件纯文本 | BSD-2-Clause，https://github.com/commonmark/commonmark-java |
| desugar_jdk_libs 2.1.5 | Android 8.0 的 Java 标准库兼容 | 上游 Apache-2.0 / GPL-2.0 with Classpath Exception 等许可，https://github.com/google/desugar_jdk_libs |
| UI UX Pro Max 2.15.0 | 设计指导，仅开发时使用 | MIT，https://github.com/nextlevelbuilder/ui-ux-pro-max-skill |
| JUnit / Robolectric / MockWebServer / GreenMail | 测试，仅开发时使用 | 各上游项目许可证，不打包到 Release |
