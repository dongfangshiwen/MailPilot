# MailPilot 1.8.0（10）

本版继续使用 Flutter 界面，手机直接连接邮箱、文字及视觉模型 API。无需电脑、自建后端、OCR 或本地模型权重。Android 8.0 起可安装。

## 新界面

输入框保留单行起步、最多四行。工具行左侧是紧凑的“思考／搜索”胶囊，右侧是添加资料和语音／发送按钮，中间留白。胶囊点击区域至少 48 dp，窄屏、大字体隐藏装饰图标；选中不改变宽度。

设置 → **搜索与语音** 打开底部抽屉；联网搜索、语音输入共享该入口。长按输入框“搜索”也能打开。服务商、识别方式、语言在抽屉内选择，返回保留填写内容。切换服务商时分别保留本次输入，避免把一家的 Key 自动填给另一家。保存当前标签页配置后关闭并浮动提示；“连接诊断（可选）”放在最后。语音识别内容只进入输入框，不自动提问或发信。

## 保存后即可尝试读图

## 文字模型如何看图

应用内部使用“视觉模型读取 → 带来源的观察 → 主模型分析”的方式。自动模式优先尝试当前模型，再考虑同接口已配置的视觉型号和同厂商默认助手。设置中“视觉助手”可固定已配置型号；旧版指定的视觉配置保留为固定助手，选择“自动选择”可恢复自动路由。

默认助手为火山 `doubao-seed-2-0-lite-260428`、百炼 `qwen3-vl-flash`、DeepSeek `deepseek-v4-flash-vision-exp`。只在已识别的官方标准地址上自动搭配，复用当前完整地址与密钥，不改地域、不切换套餐、不跨厂商转移 Key。火山标准 `/api/v3` 保留原配置；未知代理、Coding Plan 等其他产品地址需要明确配置视觉助手。普通文字模型没有凭空获得图像输入能力，实际读图由辅助视觉型号完成。

辅助读取不继承聊天本轮思考档位。仅上传提交问题时选中的图片、PDF 页或 Office 图片，每批最多 4 张，保留 T轮次:S片段 来源。批量结果缺编号、编号重复或格式不完整时，只补读未正确定位的图片一次；客户端绑定来源。权限、限流、网络失败不转成“不支持视觉”，也不会因此继续尝试其他型号。进度及完成回答显示实际读图型号。

设计参考开源项目的协作方式：[dsh-vision-helper](https://github.com/Yuuz12/dsh-vision-helper)、[DeepEye](https://github.com/Favio8/dsh-plugin-deepeye)。实现运行于 Android，不安装这些桌面插件或 MCP 服务。

## 诊断、故障与重试

连接诊断分别记录文字、SSE 流式、工具、图片请求及失败原因。图片诊断展示模型返回的观察，不再以“回答是否包含红色一词”作为使用门槛。请求被接受只说明连接可用，不保证视觉理解准确。

诊断绑定接口、型号和凭据版本。改配置名称、思考档位不清除声明能力；改地址、型号、Key 会使旧诊断过期。旧 `supportsVision=false` 按未确认处理。Room v7 自动迁移到 v8，保留账号、加密密钥、邮件、草稿、会话和摘要。

失败信息显示在当前回答处，不重复显示顶部红条。只有实际思考参数错误才出现“恢复默认思考并重试”；视觉问题显示“选择视觉助手”，权限问题显示“修改配置”。失败和停止的回答不可“写成邮件”。配置修复后点“重试本轮”，复用原问题、资料和页码快照，在原会话接收流式回答。已清理的资料不能恢复，会提示重新选择。
