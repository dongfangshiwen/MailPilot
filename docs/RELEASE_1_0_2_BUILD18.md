# MailPilot 1.0.2（18）· 对话版本界面修订

按用户要求继续使用正式版本 1.0.2，内部构建号从 17 递增到 18。沿用原签名，可直接覆盖此前 1.0.2。不要卸载旧版；已有账号、模型、邮件、草稿及会话保留，Room 仍为 v8。模型默认最大输出长度继续为 4096 Token。

## 使用方式

- 点击或长按用户消息气泡，打开底部“消息操作”面板，可修改输入或复制消息。移除气泡下方的常驻铅笔图标。
- 点击“修改输入”后，在底部输入框编辑并重新发送；点 × 取消会恢复修改前未发送的文字。
- 有多个版本时，气泡下方显示中性灰的 `‹ 1 / 3 ›`。左、右箭头直接在聊天页切换对应的问题、思考内容、回答和来源，不再弹出版本抽屉。
- 两次、三次或更多次编辑均使用同一套灰色页码与箭头。第一版禁用左箭头，最后一版禁用右箭头；选择状态不会变成蓝色按钮。只有一个版本时不占用版本栏。
- 历史版本仅供查看，暂时隐藏最新分支的后续消息。点击“回到最新”或右箭头切回最后一版可继续聊天，未发送文字会恢复，键盘不会自动弹起。历史草稿不能发信或修改；发送仍需核对最新确认卡片。
- 查看版本只读本机历史，不调用模型、不下载附件，也不改写会话或 SMTP 记录。正在生成或修改输入时，版本切换暂不可用。

消息气泡继续使用中性浅灰／深灰底色。箭头为 20 dp 线条图标、48 dp 点击区域，页码为 12 sp 普通字重，支持字体缩放。操作抽屉使用主题表面色。

## 实现与兼容

`messageVersions` 在原有问题和回答文本之外提供完整消息展示数据，保留实际模型思考、来源及草稿快照。Flutter 在当前聊天列表显示选定版本，最新分支和编辑时使用的资料快照保持不变。旧 JSON 存储无需迁移，旧版仅有文本的版本记录仍可展示。

源码、Windows 构建和打包脚本均包含在交付包中。签名材料继续单独保管，不进入源码包。发布命令：

```powershell
./scripts/Build.ps1 -Mode Test
./scripts/Build.ps1 -Mode Release
./scripts/Package-Delivery.ps1
```
