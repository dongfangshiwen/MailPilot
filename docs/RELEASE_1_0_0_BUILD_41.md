# MailPilot 1.0.0（41）：资料复用、进度与工具上下文审查

日期：2026-09-13。基线为构建 40；版本保持 1.0.0，内部构建号递增至 41。Room 保持 v9，设置页不展示构建号，保留发送确认提示。

## 根因与优化前后

| 已确认的问题 | 构建 40 的复现 | 修复后的行为 |
|---|---|---|
| 把旧展示文字作为动作缓存 | 先读取链接说明，再抓取网页，再以相同参数读取本地来源，仍返回旧说明 | `read_evidence` 根据当前授权来源重新生成预算内摘录，完整网页由既有读取缓存复用 |
| 重复搜索返回过时摘录 | 搜索→读取网页→再次搜索相同问题，最后工具回执还是搜索时的旧片段 | 搜索采集缓存保留来源编号，显示时重新绑定当前来源，复用已取得网页正文；模拟完整 Agent 仍只有一次搜索和一次网页访问 |
| 同页不同引用虚增进展 | 同一网页相同文字和范围，换个引用编号，进度从 1 增到 2 | 以完整 URL、内容版本和范围合并已读记录；迁移旧编号范围不增加进展，新增内容或不同动态路由分别计数 |
| 引用编号被当作正文已经展示 | 最新结果只含 `[S1] 未展示摘录`，精简却移除了旧的有效事实 | 根据实际展示的摘录文字去重，仅出现引用编号不再排除来源目录 |
| 混合工具结果被错误精简 | 文本工具回执同时含网页和邮件卡片，被整体替换成网页记录 | 根据应用记录的结构化调用确认全部动作类型；含邮件卡片、草稿或未知动作的混合回执整体保留 |

以上新增的五个复现用例先在构建 40 代码上运行，五项均失败，见 [修复前用例](test-evidence/build41/review-before.xml) 和 [初测日志](test-evidence/build41/review-before.log)。最终新增十项原生回归通过，见 [修复后用例](test-evidence/build41/review-after.xml)。其中两项完整 Agent 用例分别覆盖原生工具和文本工具模式；每个用例为 4 次固定模型决策、1 次网页采集，搜索用例为 1 次搜索采集，没有额外模型整理请求。

## 实现与冗余清理

- 资料采集与展示分离：搜索用 `evidenceReceipts` 保存来源关联，网络结果继续由既有搜索／网页工作流持久化。每次展示根据当前正文、问题和预算生成；不再复用过时的序列化工具摘录。访问到旧的资料展示缓存时移除该条冗余回执，草稿操作回执保持不变。
- `ResearchProgress` 的 JSON 版本更新为 2，旧网页阅读范围按当前授权来源延迟合并，保留已有计数。新网页内容、不同查询参数或片段不会混为同一版本。账号／会话隔离继续由轮次和来源范围保障。
- `ToolContextView` 读取已记录的调用列表，不再依赖网页里出现的“动作……”字样分类；删除只排除两种草稿名称的局部分支。无法解析的旧调用保留完整回执，不能推测它只是网页操作。
- 来源目录只依据实际已显示文字去重，保留整体请求预算约束。原生和文本模式继续保留最新必要工具响应及协议配对。
- `WebReadResult` 分别返回实际读取数与复用数，避免移除旧展示缓存后把正常复用显示成零次；同一 URL 的多个引用只计一个网页。

没有根据公司、域名、发票内容或用户问题增加特殊修复规则；没有新增模型规划、评判或整理请求。网页策略仍为 v3，有效分析缓存不会因本轮升级统一失效。自动 GET、公网地址校验、重定向限制、七轮收集后最终回答、草稿版本检查及发送确认保持不变。

## 测试与审查结果

- Flutter 390 项通过，静态分析无问题；本轮没有修改 Dart 界面逻辑。
- 原生 316 项：314 通过、2 项真实 IMAP 条件测试跳过，最终无失败。
- Android Lint：0 错误、13 项既有依赖／目标版本／KTX 建议。
- 新增回归覆盖旧摘录被新正文替换、搜索不重复采集、预算变化、来源失效、重启恢复、不同网页版本、旧范围迁移、混合回执、页面引文、实际文本去重及复用数量。

全套初测曾出现一条并发传输测试失败：服务端稍后接收已取消请求，使服务器计数从 7 变成 8。原断言用它判断客户端是否发起“下一次”连接，存在时序误差。现改用客户端请求边界计数，继续验证解压后总量不超过 12 MiB、达到上限后新读取不建立连接；没有放宽生产额度。保留 [初测证据](test-evidence/build41/concurrent-test-initial.xml) 和 [最终通过记录](test-evidence/build41/concurrent-test-final.xml)。

日志：[Flutter 与初次全套检查](test-evidence/build41/full-initial.log)、[最终原生与 Lint](test-evidence/build41/final-native-tests.log)、[原生汇总](test-evidence/build41/native-summary.json)、[Lint 汇总](test-evidence/build41/lint-summary.json)。
