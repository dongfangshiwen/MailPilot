# MailPilot 1.8.4（14）

## 输入框

- 深度思考、智能搜索的文字使用更柔和的颜色和中等字重；搜索图标改成简单的放大镜。开启状态仍有浅色填充与描边。
- 添加、语音、发送的圆形外观统一从 32 dp 缩为 28 dp，内部图标为 16 dp，描边 1.2 dp；添加与语音使用更浅的灰色描边。点击区域仍为 48×48 dp，位置和大小不会随语音／发送切换而变化。

## 邮件图片附件

- 本轮针对邮件的图片附件。邮件正文外链图片的处理不变，不增加远程图片自动加载。
- 附件列表只展示文件名、大小和图片图标，增加“点按预览”提示。点击哪一张就加载哪一张；打开邮件、浏览附件列表和勾选用于分析，都不批量下载图片，也不自动调用模型。
- 点开后立即进入带加载状态的预览页，读取在后台完成。支持双指缩放、返回及失败后单独重试。异步读取结束不会把已返回的用户重新带入预览。
- 预览不再依赖附件分析流程；图片 MIME 和常见扩展名都可识别，兼容标为普通文件的 JPG／PNG。预览会按设备解码能力处理图片，较大图片生成缩小的预览；GIF 等动图显示静态首帧，不作为动画播放器。
- 原附件下载缓存继续复用；预览缓存按原文件路径、修改时间和长度复用。相同附件的并发下载串行处理，避免写入同一个临时文件。
- “其他应用打开”和“保存到手机”改成底部两个并排、等高的图标操作，字号放大时可换行。两项均使用原始附件，不导出压缩后的预览图片；对通用 MIME 的常见图片补充正确类型。保存位置通过 Android 系统文件选择器决定，不等同于自动存入相册。
