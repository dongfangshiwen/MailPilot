# MailPilot 1.4.0（6）变更与验证

## 可查看的思考过程

读取配置模型公开返回的 `reasoning_content`，在回答前实时展示；正文开始时自动折叠，用户可重新展开。历史记录保留思考、耗时与停止／中断状态。未返回思考内容时不虚构，不展示协议密文。

显示与存储最多保留 128000 个 UTF-16 字符，超限明确提示；工具继续调用所需的原始协议消息仍完整保留。上下文压缩只使用对话正文，不把历史思考重新灌入请求。Room 从 v3 自动迁移到 v4，原回答及摘要保留。

协议依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)、[火山引擎 Ark 流式类型](https://github.com/volcengine/volcengine-python-sdk/blob/master/volcenginesdkarkruntime/types/chat/chat_completion_chunk.py)。折叠交互根据用户要求实现，不声称与某个版本的厂商 App 完全相同。

## 邮件顺序及同步

旧代码先按 IMAP 消息序号截取一页，再将已取回的邮件按日期展示。如果历史邮件最后导入、序号与日期相反，最新日期的邮件可能根本没进第一页。已用本地 IMAP 测试服务按相反顺序导入 24 封邮件复现该条件。

新代码先按日期排序，再分页：优先使用服务器 SORT DATE；服务器不支持或拒绝 SORT 时，按每批 200 封获取信封及接收日期元数据，保留当前分页所需候选，选定后才下载正文。相同日期按序号降序；无 Date 时使用接收日期。展示列表采用服务器查询返回的 ID 顺序，分页去重，不让旧缓存挤入当前结果。

对于没有 SORT 的大型邮箱，首次全量元数据排序可能较慢；不会暗中只排序末尾若干封。依据：[RFC 5256](https://www.rfc-editor.org/info/rfc5256/)、[Angus IMAPFolder](https://eclipse-ee4j.github.io/angus-mail/docs/api/org.eclipse.angus.mail/org/eclipse/angus/mail/imap/IMAPFolder.html)。这解释了可复现的代码问题，未使用用户真实邮箱检查其导入历史。

启动只读取本地邮件缓存，不自动刷新。后台同步默认关闭；之前显式保存的频率保留，可在设置关闭。手动下拉或菜单刷新、搜索及用户选择文件夹时按需连接邮箱。后台同步若主动开启，受系统调度影响。

## 草稿、发送及简化布局

- 分析回答可点击“写成邮件”，工具生成的草稿可点击“查看草稿并发送”；允许更改目标邮箱、抄送、密送及附件。
- AI Markdown 在进入编辑页或草稿库时经 CommonMark 转为纯文本，保留自然段、列表、表格内容、链接地址和代码内容；已有草稿可手动转换。聊天回答仍保留 Markdown。
- 手动编辑、保存和 SMTP 发送不会再次悄悄转换。发送预览展示同一草稿版本的实际正文；点击最终确认才会发送。重复点击与不确定结果仍有原有保护。
- 保存成功、同步进度／结果均为浮层，不新增页面占位行，成功提示约 3 秒后消失，可关闭；浮层避开底部主按钮。异步清除通知不会清除同时出现的错误。
- 附件改为小图标、单行文件名和尺寸说明；长名称省略并可长按查看全名，勾选前后高度一致。
