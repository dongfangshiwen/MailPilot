# MailPilot Flutter UI 规范

## 1.0.2 构建 19 版本栏间距

数字最小宽度 32 dp，左右箭头各向内对齐，距数字区边缘 4 dp；每个箭头保持独立的 48 × 48 dp 点击区域。保留 12 sp 灰色数字及大字体自然扩展。

## 1.0.2 构建 18 对话版本

点击用户气泡显示主题底部操作面板，移除常驻编辑图标。多版本使用中性灰页码和左右箭头，在聊天列表直接显示选定问题与对应回答。页码 12 sp，箭头 20 dp，点击目标 48 dp；普通字重，禁用箭头降低透明度。气泡浅／深灰色随主题切换，多次编辑不加蓝色强调。历史版本保持只读，回到最新恢复未发输入。遵循 UI UX Pro Max 的触摸区域、主题一致性和返回路径规范。


## 1.0.2 对话修改

用户气泡右下角提供 17 dp 铅笔图标，点击范围 48 dp；参考用户提供的 DeepSeek 示例，在原输入框顶部显示“修改输入”和 ×，不弹出另一套大型表单。输入框保留紧凑思考／搜索胶囊和同尺寸发送按钮，下面一条轻量文字说明沿用原轮次资料，避免误用当前新选的附件。暂存普通输入内容，取消后恢复。生成时先停止才能编辑。

有多个版本时显示紧凑版本入口。底部面板包含上一版／下一版、版本计数和关闭按钮，正文区域可滚动；只读展示历史问题与对应回答，继续对话使用最新分支。没有恢复快照的应用操作消息不展示无效编辑入口。

本版截图见 `screenshots/release102/`。界面预览使用合成测试资料，真实 Release 不显示预览标识。正式邮件从结构化草稿显示为既有确认卡片，不使用 JSON 代码块表示发送卡片。


1.0.1 附件与 PDF 规范优先于旧说明：邮件详情、资料管理共用紧凑附件行，22 dp 文件图标、文件名最多两行、类型／大小小字、右侧独立 48 dp 勾选。名称预览与页码编辑分开；资料按邮件分组，超限提示仅在管理内。PDF 顶部紧凑文件信息、单页居中／多页双列缩略图，大字体单列。卡片 12 dp 圆角、恒定 1.5 dp 边框；页面勾选不改变尺寸。只渲染可见卡片，480 px 缩略图串行排队，退出取消。底部唯一主操作为“确认选择 · N 页”，清空后为“取消选择此附件”；返回不提交修改。放大预览背景跟随 surface 主题。实现见 `lib/materials_sheet.dart`、`lib/pdf_picker.dart`，截图见 `screenshots/release101/`。

1.0.0 增补：输入工具文字和描边在 1.8.4 基础上略微加深；搜索图标使用对称的地球线框，由外圆、经线与赤道组成，16 dp 矢量画布、1.2 单位圆角描边，随主题着色（`lib/search_globe_icon.dart`）。按钮大小维持 28 dp，触摸区域维持 48 dp。打开左上角菜单前释放输入焦点，返回当前对话保留文字且不弹键盘。

1.8.4 输入框规范优先于下文的早期页面描述：思考／搜索使用 32 dp 细描边胶囊，选中时浅蓝填充，文字降低字重并使用更柔和的主题色；思考使用线条灯泡，搜索使用简单放大镜，思考完成使用单勾。添加、语音及发送共用 28 dp 圆形外形、16 dp 内部图标与 48 dp 点击区域，描边 1.2 dp；添加与语音采用柔和灰色。空输入显示语音波形，输入后原位换成发送箭头。普通空间显示完整文字和图标，窄屏先缩短文字，大字体按需隐藏装饰图标，开关切换不改变宽度。浅色输入框使用白底与轻阴影，深色沿用 #222427。当前代码以 `lib/chat_composer.dart` 为准，截图见 `screenshots/release184/`，参考为用户提供的 DeepSeek 截图。

邮件图片附件默认只显示文件名、大小和小图标，点按单个附件才下载并预览。预览页即时显示加载状态，图片居中适配、双指缩放；底部两个操作等宽等高，图标 20 dp、文字 12 sp、最小高度 64 dp。操作使用原始文件；大字体时文字允许换行，保持对齐。失败在当前预览页提供重试，返回后异步完成不重新打开页面。实现见 `lib/attachment_preview.dart`、`lib/editor.dart` 和 `lib/screens.dart`。

模型设置采用页面轻底色和 surface 分组卡片：连接配置、模型、高级参数，圆角 18、间距 12、卡片内边距 16。字段外置标签 12、输入 15、圆角 12；长度字段按宽度和字号选择横排或纵排。高级参数无粗分隔线，三个选项全部使用带标题、关闭、勾选的底部面板，最大高度为视口 78%，长列表滚动。保存固定在底部并避让键盘；右上角“模型选项”集中默认用途、诊断和删除。选项图标 20、标题 15、说明 12，删除独立确认，返回保留未保存内容。实现见 `lib/forms.dart` 与 `lib/model_controls.dart`。

本版按用户要求简化布局：默认进入对话页，邮箱、草稿、历史和设置位于侧边栏，移除首页多栏目和底部常驻导航。参考 DeepSeek 的对话页信息层级及豆包的简洁输入入口，使用 MailPilot 自有名称、图标、配色和代码。

在线参考：[DeepSeek 官方 Android 页面及截图](https://play.google.com/store/apps/details?id=com.deepseek.chat)、[豆包官方移动端页面](https://www.doubao.com/download/mobile)。辅助设计指导：[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)。参考日期：2026-09-07。未使用 Figma 文件作为实现来源。

## 页面结构

- 思考内容：只展示接口返回的可读内容，初始展开；正文开始后自动折叠，点击可重新查看。短内容随文字收缩，长内容达到高度上限后内部滚动；结束后保存耗时和停止状态。
- 轻提示：保存成功、同步进行中及结果用浮层，结束约 3 秒后消失；浮层避开底部主要操作，错误信息仍可手动关闭。
- 附件：20 dp 图标、单行省略文件名、小号尺寸说明；完整名称通过 Tooltip 查看，勾选不改变高度。
- 发送：Agent 根据聊天中的目标邮箱起草，展示不可变邮件确认卡片；用户检查后在卡片点击确认，手机通过 SMTP 提交。卡片可进入修改，修改后必须重新展示确认。

- 对话主页：顶部菜单和新对话按钮；中央简短欢迎语及少量建议；底部柔和灰色输入区，集中放置“选择邮件”、模型入口和发送问题按钮。已选资料在输入区附近持续显示，可展开查看。
- 未连接邮箱：欢迎语“有什么想聊的？”，未配置模型时优先显示“添加模型”；配置模型即可直接聊天。输入区的“连接邮箱”是可选入口。
- 上下文整理：沿用回答状态行展示批次进度；有摘要时显示一行“已整理 N 条早期消息”，点击后从底部展开可复制的摘要原文。新对话不显示旧摘要，不额外增加常驻面板。
- 邮件：轻量列表行，保留发件人、时间、主题、真实正文预览和附件数。搜索按需展开，账号使用菜单切换；文件夹从底部选择器独立刷新，失败保留缓存与重试，附未读开关。勾选与阅读分别操作。
- 详情：可复制正文；地址按需展开；附件独立选择或预览；底部回复与分析。
- 助手：用户问题使用浅灰气泡，回答以 Markdown 直接排版，正文 16 / 行高 1.65。表格和代码局部横向滚动。流式状态放在回答下方，停止按钮位于输入框右下角；支持复制和点击来源编号。
- 草稿：收件人、主题和正文优先展示，抄送 / 密送按需展开。附件与抄送操作同行，Markdown 转换和删除放在右上角更多菜单。底部主按钮回到聊天展示完整邮件确认卡片。
- 设置：左上角明确返回主页，系统返回同样生效。邮箱和模型编辑页先返回设置。模型高级参数入口说明包含“思考模式、思考档位与输出长度”，展开后按服务商显示档位或预算。
- 邮箱预设：每个选项持续保留 18 dp 的勾选图标位置，选中时仅改变图标可见性与颜色，点击不会改变选项宽度、行数或邮箱输入框位置。选项集合仍按屏幕宽度和系统字体自然换行。
- PDF：明确显示总页数、已选数量，默认前 10 页，最多 20 页，空选择不可提交。图片支持缩放。

支持浅色 / 深色 / 跟随系统，系统字号缩放，键盘避让和小屏滚动。错误在当前页显示，保留输入。邮件内容不会驱动权限或发送操作。

## 1.6 交互补充

清空选择不更换会话，保留滚动与历史分析。邮件同步按钮在工作时显示进度并允许取消，所有文件夹先显示缓存；后台进度使用浮动提示，不新增常驻占位。草稿列表及确认卡片的更多菜单提供重新拟写和删除，保持发送为唯一主操作。

本轮参考 UI UX Pro Max 的 Flutter 异步状态、状态保留和菜单规范；截图见 screenshots/release160，均为标记清楚的界面样例。

## 1.7 输入框与操作面板

普通字号下输入区内容高度约 100 dp，外边距左右 12、上 6、下 8；圆角 24。文字 16 sp / 1.4 行高，1–4 行，工具行 48 dp。选中状态使用蓝色浅填充，图标尺寸固定，避免勾选图标造成宽度变化。宽度不足或字体放大时只显示“思考 / 搜索”，无论状态如何点击区域至少 48 dp。

模型位于顶部标题菜单。资料摘要位于输入区内部，点击管理。加号面板和草稿操作面板使用 surface 色及拖动条，适配深色；编辑、重拟、删除有独立图标，删除保持红色并另行确认。缺收件人卡片使用蓝色“补充收件人”主操作，旧卡片提供“查看最新版本”，避免无解释的灰色按钮。

新页面在 docs/screenshots/release170 中以标记为 fixture 的截图交付；真实 release 安装截图单独命名。页面代码预览使用既有 main_preview.dart，不需要 Figma 授权。


## 1.8 组件调整

采用 UI UX Pro Max 的触摸目标、表单状态保留与返回路径原则。输入框普通字号约 100 dp，左侧两个固定标签胶囊，最小触摸区域 48×48 dp；胶囊装饰高度约 32 dp，选中不改宽度。小屏和大字体隐藏装饰图标，保留“思考／搜索”文字，中间 Spacer 将加号和语音推至右侧。

搜索与语音共用主题底部抽屉。顶部关闭、两个标签页；表单区域可滚动并避让键盘。选项为抽屉内部页面，Android 返回退回表单；IndexedStack 保留两个标签页表单。底部主按钮保存当前配置并关闭，连接诊断位于最后。正常分析错误就在回答位置显示，消除重复顶部红条。
