# MailPilot 1.0.0（21）

按用户要求继续使用 1.0.0，内部构建号从 20 递增至 21。保留原包名、发布签名与 Room v8；基线是已交付的 1.0.0（20）。

## 修改内容

- 移除输入框上方常驻的“已整理 N 条早期消息”，恢复连续的聊天与输入区域。
- 左上角菜单新增“对话摘要”；仅在当前对话已有摘要时出现。点击后查看数量及排版后的摘要，保留关闭入口和滚动阅读。
- 引述详情复用聊天的 Markdown 排版，显示标题、加粗、列表和表格。明确包在 `markdown`／`md` 代码围栏中的文档按正文显示；真正的代码围栏保留。
- 引述页右上角“查看原文／排版阅读”切换只改变显示，原始引用内容始终保留。普通文本的换行仍保留。
- 查看摘要、展开引用和切换原文不触发模型请求；文字中的网络图片仍使用占位文本，不自动下载。附件原图延续原有用户点选后的按需加载。

## 原因与代码审查

原界面把摘要按钮放在聊天列表与输入框之间，所以摘要一旦生成就持续占用输入区。现在删除该固定布局和内联摘要弹窗，将摘要阅读提取为独立组件。

原来的引述页及摘要详情使用 `SelectableText`，直接展示 Markdown 字符串。现在统一复用现有 `MarkdownReply`，没有引入另一套解析器，也不把转换结果覆盖保存到原始资料中。排版与 SMTP 正文转换仍是不同用途，本次不改变邮件发送内容。

补充检查了菜单返回的焦点行为、摘要窗口打开期间切换会话、原文切换是否重复读取，以及外部图片和未知来源链接的处理。摘要绑定打开时的会话，切换会话后不会继续展示旧摘要或新会话内容。
