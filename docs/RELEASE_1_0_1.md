# MailPilot 1.0.1（16）

本版优化邮件附件选择和 PDF 选页。沿用原包名、发布签名及 Android 8.0+ 支持范围；Room 保持 v8，新增选择模式与实际页码写入原有 JSON 字段。

## 使用方式

1. 新勾选邮件，自动选中缓存清单中的 DOCX、XLSX、PPTX、PDF、TXT、JPG/JPEG、PNG、WebP 附件。这里只更新勾选，不下载、不渲染、不调用模型。旧会话的选择范围不因升级扩大。
2. 点输入框中的已选资料摘要，展开“本次分析资料”。附件按邮件分组，支持逐个取消、“全选可分析附件”和“只保留正文”。文件名最多两行，长按查看全名。点击文件名预览；右侧勾选框只选择。
3. PDF 初始显示“默认前 10 页，页数待读取”；提问时实际取前 10 页，不足 10 页取全部。点页码入口只下载当前 PDF，进入缩略图选择器。点图可放大，点勾选框更改页码，最后确认；返回不提交修改。清空后可用底部按钮取消该附件。
4. 提问时才读取剩余已选资料。超过总量仍保留勾选，先打开资料管理，输入的问题保留。若下载或解析后才发现实际超限，会在该条回答中指出原因；调整后点击“按当前资料重试本轮”。损坏、加密、无法下载或处理失败的附件会显示文件名，不跳过后继续生成完整分析。
5. 清空、重新选择、跨文件夹查看以及修改页码均保留当前会话。生成中更换资料只影响下一轮。本轮使用独立快照，解析出的 PDF 实际页码也写入快照；普通重试沿用它，明确“按当前资料重试”才替换资料。

## 限制与加载

| 项目 | 上限／行为 |
| --- | --- |
| 单个分析文件 | 20 MB；超限或不支持格式不会自动勾选，附件行显示原因 |
| 每轮附件 | 10 个，包含手机导入文件，按附件 ID 去重 |
| 每轮附件大小 | 合计 50 MB；未知大小允许选择，读取时检查实际大小 |
| 每轮视觉资料 | 20 张，合计计算图片、PDF 页面和 Office 嵌入图片 |
| 单个 PDF | 默认前 10 页，可明确选择最多 20 页 |
| Office 解压／文字 | 保留解压读取 100 MB、整轮文字 24 万字限制 |
| PDF 缩略图 | 最长边 480 px，单线程，按可见卡片加载；无整份预加载，离开取消排队请求 |
| 放大页面 | 只渲染当前页，最长边 2048 px；复用对应缓存 |

附件清单尚未同步完整时显示“附件清单待同步”。后台补齐清单不会自动增加已选资料，可主动使用“全选可分析附件”。手动取消的附件在返回页面或刷新后继续保持取消；取消整封邮件再勾选则重新应用默认选择。

所有资料限制在搜索关键词规划、视觉请求和回答请求之前检查。实际页数和 Office 图片量可能需要本地解析后才能确定；解析超限后停止，不自动删减。聊天资料不会自动成为发送附件，原来的 SMTP 用户确认机制不变。

## 新界面

附件行采用主题浅底容器、22 dp 类型图标和右侧独立勾选，触控区域至少 48 dp。PDF 单页居中卡片，多页双列；大字体改为单列，边框选中时不改变卡片尺寸。失败可重试预览，不影响页码选择。

## 构建、校验与安装

Windows 构建沿用 `scripts/Build.ps1`，`pubspec.yaml` 为版本来源。运行 `Build.ps1 -Mode Test` 执行 Flutter、原生单元测试和 Lint，`Build.ps1 -Mode Release` 生成同签名 APK。PDF 设备界面测试入口是 `integration_test/ui101_test.dart`，原生覆盖 `Selection101DeviceTest.kt`。

请直接覆盖安装 `MailPilot-1.0.1-flutter-release.apk`，不要先卸载。校验值见同目录 `.sha256` 文件。源码包及完整交付包由 `Package-Source.ps1` / `Package-Delivery.ps1` 生成；不包含 `.signing`、凭据、本机 SDK、构建缓存或模拟器。
