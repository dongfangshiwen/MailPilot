## 修复菜单返回后自动弹出键盘

此前，点击左上角菜单没有释放输入框焦点。Flutter 抽屉暂时转移焦点后，关闭时会恢复原输入框焦点；即使用户此前已经收起键盘，返回也可能重新触发键盘显示。

本版在打开左上角菜单前释放输入焦点。关闭菜单或选择“AI 助手”回到当前对话时，键盘保持收起，已输入内容保留；主动点击输入框才再次弹出。原有发送、语音和附件入口保持原行为。

## 输入框细调

按本轮补充要求，深度思考、智能搜索以及添加、语音按钮的文字和描边比 1.8.4 略深。保留 28 dp 圆形外观、16 dp 内部图标和 48 dp 点击区域，发送仍在有文字时原位替换语音。

联网搜索采用简洁的地球线框：外圆、一条经线与一条赤道，左右对称，16 dp 画布、1.2 单位圆角描边，随主题着色。与添加、语音按钮保持相同的线条粗细，直接使用 Flutter 矢量绘制，不引入图片或额外运行库。
