# 1.2.1 邮箱选项布局修复

## 原因与改动

手机“连接邮箱”页使用 `Wrap` 排列 `ChoiceChip`。旧实现由组件在选中后插入勾选图标，导致选项宽度动态改变。在临界屏宽下，后续选项会换行，下面的邮箱输入框随之下移；切换到另一个选项又会重新排列。

修复后关闭组件自带的动态勾选位置，在每个选项内持续保留 18 dp 图标空间，选中时显示勾选。选项保留标准选中语义、触控反馈和浅／深色主题。换行由屏宽和系统字体决定，不再由当前选中项决定。高级设置的收信／发信加密下拉框也限制在可用宽度内，避免大字体时横向溢出。

## 验证

- 修复前回归测试稳定失败：320 dp 屏宽切换 QQ → 163，QQ 选项宽度缩小约 20 dp。
- 修复后 19 项 Flutter 测试通过；其中布局回归覆盖 320、360、393、430 dp，字体比例 1.0、1.6、2.0，以及所有邮箱选项和选中动画中间状态。逐一比较所有选项的矩形位置、尺寸和邮箱输入框位置。
- `flutter analyze` 通过，无问题。
- Android 8.0 / API 26 模拟器上，2 项 Flutter 功能测试及 4 项原生平台测试通过；功能流程逐一点击所有邮箱选项并比较位置，截图见 `screenshots/mailbox-layout/`。
- 旧版完整邮件／模型协议测试记录保留在 `VALIDATION.md`；本次只修改 Flutter 表单布局与版本信息。

证据前缀：`test-evidence/mailbox-layout-*`。未连接用户实体手机，设备检查使用 Android 模拟器。

## 安装

1.2.1（versionCode 4）已构建验证；此修复现合并交付于 `MailPilot-1.3.0-flutter-release.apk`（versionCode 5）。包名和发布密钥沿用旧版，选择覆盖升级可保留已有邮箱及模型配置。源码和交付 ZIP 同步提供，文件旁附 SHA-256 校验值。
