# MailPilot 1.8.3（13）

- 深度思考开关用简洁的线条灯泡图标，移除交叠轨道图形；回答中思考完成的双勾改为单勾。正在思考时仍显示细线进度环，自动折叠行为不变。
- 添加、语音和发送的圆形外观从 36 dp 统一缩至 32 dp，内部图标从 21 dp 缩至 18 dp，描边相应减细。三个按钮仍有相同的 48×48 dp 点击区域。
- 空输入只显示语音，有文字后发送原位替换语音；停止回答和结束录音沿用同一按钮位置与尺寸。
- 模型设置重排为连接配置、模型、高级参数三组。浅灰页面配合主题卡片，减少字段间空白和说明，移除高级参数的粗分隔线。上下文和输出长度在空间足够时并排，小屏或大字体自动纵排。
- 思考模式、思考档位、输出长度参数全部改为底部选择面板，替换遮挡表单的大型下拉浮层；服务商和内置型号使用同一组件。面板带标题、关闭、当前项勾选和按需说明，可滚动，返回保留编辑内容。
- 保存按钮固定在底部并避让键盘；默认模型、固定视觉助手、诊断、删除集中到右上角“模型选项”，删除仍需确认。不再在保存按钮下堆叠操作和说明。
- 邮箱、视觉助手、联网与语音协议沿用 1.8.2，数据库保持 Room v8。直接覆盖安装，不需要重新配置账号。

本轮仅调整 Flutter 界面，原生单元测试及 Lint 沿用 1.8.1 记录；不重复调用真实邮箱、云端模型或语音服务。

## 验证

- `flutter analyze` 无问题；Flutter 71 项测试通过。更新模型参数测试为实际点击底部面板，确认参数、档位／预算互斥及保存值正确。
- 输入区回归覆盖 320／360／412 dp、1.0／1.6／2.0 字号及深浅色；模型页覆盖 320 dp／2.0、360 dp／1.6、412 dp／1.0 的深浅色、键盘展开、取消选择、编辑内容保留、可选诊断和确认删除。
- API 36 的深浅色界面流程通过：语音／发送原位切换、模型表单、三个参数面板及返回。截图位于 `screenshots/release183/`，使用样例数据，不代表真实厂商连通性验证。
- 一次设备测试在断言通过后遇到 ADB 短暂离线，主机未完成结果收尾；保留 `test-evidence/release183-ui-transport-interruption.log`。连接恢复后重跑，完整设备流程通过，最终日志为 `release183-ui-device.log`。
- Release 版本 1.8.3（13）、原签名和 16 KiB 对齐检查通过。API 36 实测从 1.8.2 覆盖安装后，应用 UID 与首次安装时间相同，启动无 AndroidRuntime 崩溃。测试使用空配置设备，未代替实体手机全部历史数据的实测。
- 本次复用现有 API 36 镜像；临时 `MailPilot_183_Test36` 及其数据目录已删除，日常 `MailPilot_API36` 和系统镜像保留。
