# MailPilot 1.7.0（9）

本版保留 Flutter 界面、Android 本地存储和手机直连 IMAP / SMTP / HTTPS API。无需电脑、自建后端、Google Play 服务、OCR 或内置语音模型。最低 Android 8.0，目标 API 36。

## 界面与使用

- 输入框为文字区＋工具行，普通字体下内容高度约 100 dp（不含外边距）。默认一行，最多四行；长文字在内部滚动。窄屏和大字体显示“思考 / 搜索”，按钮点击区域至少 48 dp。
- 模型从顶部标题菜单切换。深度思考首次跟随模型设置，点击可为下一轮明确开关；长按恢复模型默认。档位和预算仍在模型高级参数中配置，不会被快捷开关改写。仅展示服务商实际返回的思考内容，开始回答后折叠。
- 加号可添加图片、手机文件或选择邮件；没有邮箱也能选择本地文件问答。PDF 必须确认页面，默认前 10 页、单次最多 20 页。资料摘要在输入框内，点击可管理，× 仅清除选择。
- 草稿操作统一为主题色底部面板：编辑邮件、重新拟写、删除草稿。删除需另行确认。
- 卡片缺收件人时显示可点击的“补充收件人”；也可直接说“发给 name@example.com”。保存后出现新版本，核对后点击或回复“确认发送”。旧卡片显示失效原因并可查看最新版本；发送中、待核实、已发送、已删除有独立状态。

## 写成邮件

该操作按回答 ID 读取完整回答，参与现有上下文预算与长资料整理；聊天只显示“将这条回答写成邮件”，不再复制内部提示词或截取前 300 字。可识别的旧版起草操作消息收起显示，允许查看原文。

新生成的正文在保存前转换为纯文本段落、列表和表格文字，去除 Markdown 排版、内部来源编号及常见未知署名占位符。卡片、编辑器和 SMTP 使用相同正文；用户手动修改不会在发送时被再次转换。通知邮件的发件人不会自动成为目标收件人。回复、重拟及显式语言要求沿用中英文语言规则。

## 独立联网搜索

设置 → 联网搜索：选择服务商，填写完整接口地址和对应 API Key，测试并保存。模型 Key 与搜索 Key 分别保存，均使用 Android Keystore / AES-GCM 加密。

| 服务商 | 默认完整接口地址 |
|---|---|
| 火山联网搜索 | `https://open.feedcoopapi.com/search_api/web_search` |
| 博查 | `https://api.bocha.cn/v1/web-search` |

搜索默认关闭。开启后根据当前问题规划最多两组关键词，每次五条，去重最多八条来源，再流式回答。工具模型和普通兼容模型共用流程。网页来源可打开标题、链接及实际返回的检索内容；单条超过 6000 字时明确标记节选。

关键词规划只接收当前问题，搜索服务只接收关键词，不提交邮件正文、附件或完整聊天历史。缺少对象时询问关键词；普通起草、地址修改和发送确认不自动搜索。失败明确显示“本轮未完成联网”，可重试或关闭搜索后回答，不把失败当作已联网。来源内容作为资料，不能授权读取其他邮件或发送。

协议依据：[火山官方实现](https://github.com/volcengine/mcp-server/tree/main/server/mcp_server_askecho_search_infinity)、[博查官方接口说明](https://github.com/Bocha-Labs/bocha-skills/blob/main/bocha-web-search/SKILL.md)。手机直接请求 HTTP API，不运行 MCP 服务。

## 语音输入

空输入框显示语音按钮，有文字时显示发送按钮并保留麦克风入口。点击开始，再点结束，可取消，最多 60 秒。识别结果插入当前光标位置，保留已有文字；即使识别出“确认发送”，也只填入输入框。

默认系统识别优先，需允许麦克风权限。手机是否有系统识别服务取决于厂商，不强制安装 Google Play。系统服务不存在时可使用已配置千问 ASR；系统识别失败后选择“云端重录”需要重新录音。

设置 → 语音输入：可选系统优先或直接云端、中文 / 英文 / 自动。系统自动模式跟随手机语言；云端自动模式不限定语种。云端默认 Base URL 为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，也可填写百炼业务空间专属域名，模型默认 `qwen3-asr-flash`，不支持异步 Filetrans 模型。

云端使用 16 kHz 单声道 WAV，将音频 Base64 数据直接放入 HTTPS 请求，不上传中转服务器。完成、取消、失败后删除临时文件；切到后台取消录音。连接测试提交一秒静音，仅说明接口是否响应，不能代替真人录音识别验证。

依据：[Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)、[千问 ASR 官方接口](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)。

## 数据与升级

Room v6 → v7 自动迁移，保留账号、加密凭据、邮件、会话、摘要、草稿和同步检查点。增加每轮请求选项、消息动作、手机资料及网页来源。手机资料按会话隔离，历史引用随会话保留；侧边栏长按对话可确认删除；删除会话或清理缓存回收文件。分析资料不会自动附加到发送邮件。

覆盖安装前请勿卸载旧版。继续使用原签名，签名材料仅在本机 `.signing/`，不进入交付源码。Windows 构建、签名备份及打包方法见根目录 README。
