# 阿里邮箱接入

核对日期：2026-09-08。阿里邮箱提供标准 IMAP / SMTP，MailPilot 的 Android 邮件服务可按这些协议接入；1.2.0 已添加企业和个人邮箱预设。1.8.1 使用用户授权的企业账号完成真实 IMAP 登录、5 个文件夹只读同步及增量缓存验证，并修复该服务器拒绝组合 SEARCH 的兼容问题；未进行真实 SMTP 发信测试。详情见 [1.8.1 验证记录](RELEASE_1_8_1.md)。

## 配置

进入“设置 → 添加邮箱”，选择“阿里企业 邮箱”或“阿里个人 邮箱”，填写完整邮箱地址和凭据，再点击“测试连接”。测试仅验证 IMAP / SMTP 登录，不发送邮件。保存后回到邮件列表刷新。

| 类型 | IMAP 主机 | SMTP 主机 | 加密与端口 |
| --- | --- | --- | --- |
| 阿里企业邮箱 | `imap.qiye.aliyun.com` | `smtp.qiye.aliyun.com` | SSL，收信 993、发信 465 |
| 阿里个人邮箱 | `imap.aliyun.com` | `smtp.aliyun.com` | SSL，收信 993、发信 465 |
| 企业邮箱香港地区 | `imaphk.qiye.aliyun.com` | `smtphk.qiye.aliyun.com` | SSL，收信 993、发信 465；在自定义中填写 |

服务器与端口依据：[企业邮箱官方配置](https://help.aliyun.com/zh/document_detail/36576.html)、[免费个人邮箱官方配置](https://help.aliyun.com/zh/document_detail/465307.html)。企业账号即使使用自己的公司域名，也可按服务商分配的通用服务器配置；登录用户名留空时应用使用完整邮箱地址。

## 企业账号要求

请管理员允许该账号使用第三方客户端，并开启 IMAP / SMTP 权限。如果个人或组织已开启“三方客户端安全密码”，必须使用生成的安全密码，不能用网页登录密码。相关说明见[官方配置前准备与密码问题](https://help.aliyun.com/zh/document_detail/36576.html)和[SMTP 程序发送要求](https://help.aliyun.com/document_detail/36687.html)。

个人邮箱密码说明见[官方 Android 客户端配置](https://help.aliyun.com/zh/document_detail/465545.html)。阿里邮箱凭据与阿里云大模型 API Key 是两套配置；仅收发邮件无需配置模型。

## 连接失败时

- 认证失败：核对完整邮箱地址、客户端权限和安全密码。企业组织策略可能禁止客户端，即使网页能登录也不能据此判断客户端已获准。
- 连接超时：核对上述主机、网络及 SSL 端口。企业邮箱官方文档当前说明 SMTP 587 未开放，预设使用 465。
- 证书错误：优先使用官方服务器域名；自定义服务器域名需要有效证书，应用不会忽略证书验证。
- 能登录、列出文件夹但同步提示 `BAD invalid command or parameters`：更新至 1.8.1 后手动同步。本版在服务器拒绝 AND/OR 组合搜索时分别查询并合并结果，保留未读状态和日期排序。
- 登录成功但发送被拒：核对发件地址与认证账号、邮箱配额及企业外发策略；连接测试成功不等于实际投递成功。

香港服务器及组织特殊配置可使用“自定义”。不会根据公司邮件域名自动猜测服务器。
